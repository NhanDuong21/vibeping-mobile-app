# Roadmap

## Gate 0 — stable private iPhone Web Push

**Status: PASS.** One `.ts.net` HTTPS origin, localhost-only Rust server, persistent VAPID identity/subscription, desktop PWA behavior, physical Lock Screen/background delivery, and restart survival were proven on 2026-09-02. The only tracked pre-phone state was `READY_FOR_IPHONE_TEST`.

## Gate 1 — Codex allowance data

**Status: PASS.** The signed-in local Codex installation returned real dynamic windows through stable App Server methods; primary/secondary multi-bucket data was normalized and printed as a sanitized Vietnamese summary.

## Phase 1 — walking skeleton

After both gates pass, create the smallest Angular/Ionic PWA and Rust modular monolith with generated contract, SQLite migration discipline, manual lifecycle, health, one activity slice, REST snapshot, SSE update, and Web Push outbox.

## Phase 2 — Codex attention events

Integrate approved Codex notify/hooks paths, normalize completion/return-needed/test/preview events, persist them, and deliver one end-to-end activity slice.

## Phase 3 — allowance experience

Persist normalized windows, add low/critical/exhausted policy and deduplication, then implement “Hạn mức Codex” in the mobile experience.

## Phase 4 — reliability and recovery

Harden outbox retries, stale-device recovery, offline cache/reconnect, logs/redaction, shutdown/restart, backup/restore, and the physical device matrix.

## Phase 5 — personal-production v1.0

Finish Hoạt động/Máy tính/Cài đặt, themes and accessibility, Start/Stop/Restart packaging, Windows x64 release verification, and documentation. No V1 non-goal enters without a new product decision.
